The Planning Board demo relay

This relay is run by the Planning Board project so anyone can try sharing a plan. It's a demo: it comes with no warranty, it can be down, and plans on it can be lost. For a plan that matters, keep a copy with File › Save plan to file, and for a confidential one, run a relay of your own.

What it can't see

Everything about a plan is encrypted in your browser before it's sent, with a key that's only in the share link, after the #. Browsers never send that part to a server. So the relay stores and forwards ciphertext it can't read: card titles, values, links, history and people's names included. It doesn't serve the app either, so it can't change the code you use.

What it does see

  • Which shared plans exist, by a random name, and how large each is.
  • When people connect, and from which internet address.
  • How large each change is, and when it's made.

Internet addresses are used only for rate limits, in memory, and aren't written to disk. The hosting provider keeps its own logs.

How long plans are kept

A shared plan that nobody opens for 30 days is deleted, with everything the relay held for it. Opening it from any link, by anyone, starts the 30 days again. A board that still has the plan offers Put it back, which shares it again from that copy.

Limits

Each shared plan's board, and its history, may hold up to 5 MB each. The relay keeps up to 2,000 shared plans, and each internet address may share up to 10 new plans an hour. Making new links for a plan counts as sharing a new one.

Questions

Ask in the project's issues. Never paste a share link there: anyone with it can open the plan.
